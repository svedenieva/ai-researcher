# Как настроить Claude Design у себя и править дизайн

> Простая инструкция для того, кто раньше этого не делал.
> Делай шаги сверху вниз. Почти всю работу сделает сам Claude — тебе нужно
> вставлять готовые команды и пару раз ответить на его вопрос.
> Если где-то застрял — внизу есть раздел «Если не вышло».

---

## Что это и зачем
Ты будешь править дизайн сайта прямо в **Claude Design** — мышкой и словами, без
кода. У тебя будет **свой личный проект** (ничей чужой доступ не нужен). Готовые
правки Claude потом сам оформит и передаст разработчику.

Один раз нужно всё «подключить». Дальше — только заходишь и правишь.

---

## Что нужно до начала
1. На компьютере установлен **Claude Code** (та же программа, где ты общаешься с Claude в терминале).
   Если её нет — попроси разработчика помочь установить один раз.
2. Тебе прислали **ссылку на проект** (git) и **файл `CLAUDE_DESIGN_ONBOARDING.md`**.
3. Твой аккаунт Claude умеет открывать **claude.ai/design** (ты это уже проверял — страница открывается).

---

## Шаг 1. Открыть терминал
- **Windows:** нажми «Пуск», набери `powershell`, открой.
- **Mac:** нажми `Cmd + пробел`, набери `terminal`, открой.

Откроется окно с текстом — сюда будем вставлять команды.
Вставить: скопируй строку → кликни в окно → `Ctrl + V` (на Mac `Cmd + V`) → `Enter`.

---

## Шаг 2. Скачать проект (одна команда)
Скопируй, вставь, нажми Enter:

```
git clone https://github.com/svedenieva/ai-researcher.git
```

Это скачает проект в папку. Затем зайди в неё:

```
cd ai-researcher
```

> Если пишет «Repository not found» или просит пароль — у тебя пока нет доступа к
> репозиторию. Напиши разработчику: «добавь меня в репозиторий ai-researcher».

---

## Шаг 3. Запустить Claude
Набери и нажми Enter:

```
claude
```

Если спросит про доверие папке — согласись (Yes).

---

## Шаг 4. Отдать Claude инструкцию
1. Перетащи (или укажи путь) файл **`CLAUDE_DESIGN_ONBOARDING.md`** в окно Claude.
2. Напиши одно слово и нажми Enter:

```
подключи
```

Дальше Claude начнёт всё настраивать сам. Тебе останется ответить на пару его вопросов.

---

## Шаг 5. Что Claude спросит — и что отвечать
- **Попросит войти:** набери `/design-login` и войди своим аккаунтом в браузере.
  Жди надпись **«Design-system access authorized»**.
- **Спросит, в какой проект синхронизировать:** ответь **«создай новый проект»**
  (назови, например, своим именем). Это будет твой личный проект.
- **Если предложит закоммитить свой конфиг** — ответь: **«мой config не коммить»**.
- Покажет план — можно просто согласиться.

Дальше Claude сам всё соберёт и зальёт в твой проект (это занимает время, можно подождать).

---

## Шаг 6. Править дизайн
1. Открой в браузере **claude.ai/design**.
2. Зайди в свой проект (он появится в списке).
3. Правь как удобно: **двигай мышкой**, **проси изменения текстом**, **оставляй комментарии**.

---

## Шаг 7. Отправить правки
Когда доволен — напиши прямо в чате проекта:

```
отправь в git
```

Потом вернись в терминал (где Claude) и набери:

```
/design-pull
```

Claude заберёт твои правки и оформит их для разработчика. Всё.

---

## Если не вышло
| Что видишь | Что делать |
|---|---|
| `git clone` просит пароль / «not found» | Нет доступа к репозиторию — напиши разработчику, пусть добавит тебя. |
| После `/design-login` — **403** | У аккаунта нет доступа к Claude Design — включается на стороне аккаунта, напиши разработчику. |
| «claude» не запускается | Claude Code не установлен — попроси разработчика помочь установить. |
| Claude о чём-то спрашивает, и непонятно | Ответь ему словами, что хочешь; можно написать «объясни проще». |
| Совсем застрял | Сделай скриншот экрана и отправь разработчику. |

---

## Коротко, одним взглядом
1. Открыть терминал
2. `git clone …` → `cd ai-researcher`
3. `claude` → перетащить MD-файл → «подключи»
4. `/design-login` (войти) → «создай новый проект»
5. Править на claude.ai/design → «отправь в git» → `/design-pull`
