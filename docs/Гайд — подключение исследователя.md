# AI-Researcher — как подключить и на чём он работает

**Кому:** команде AiVocado Soft
**Зачем:** завести базу под новую тему и провести исследование — из чата Claude Code или на сайте.

---

## Коротко: два режима, разные движки

| Где работаешь | Кто «думает» | Что нужно | Оплата |
|---|---|---|---|
| **Claude Code** (свой чат) | сам Claude Code | подключить MCP-коннектор | твоя подписка, токены не тратятся |
| **Сайт** ai-reesearcher.vercel.app | сервер сайта | ключ OpenRouter на проекте | по токенам с баланса OpenRouter |

Почему нельзя одно вместо другого: подписка привязана к человеку и не пулится, а для многопользовательского сайта Anthropic прямо направляет на API-ключ. Поэтому сайт для команды живёт на OpenRouter, а личная работа в Claude Code — на подписке.

---

## Часть 1. Claude Code — исследование на подписке

### Шаг 1. Подключить коннектор

Коннектор уже прописан глобально в `~/.claude.json`:

```json
{
  "mcpServers": {
    "ai-researcher": {
      "command": "node",
      "args": ["C:/Users/nehoc/ai-researcher/mcp/server.mjs"]
    }
  }
}
```

Секрет в конфиг вписывать не нужно: сервер сам читает `SUPABASE_URL` и `SUPABASE_SERVICE_KEY` из `C:\Users\nehoc\ai-researcher\.env.local`.

**После правки конфига Claude Code нужно перезапустить.**

### Шаг 2. Проверить, что поднялся

```bash
cd C:/Users/nehoc/ai-researcher/mcp
node test-client.mjs
```

Должен вывести 7 инструментов: `list_bases`, `create_base`, `add_rows`, `query_records`, `update_record`, `catalog_search`, `research_decompose`. Если создал тестовую базу — удали её потом.

### Шаг 3. Пользоваться

Отдельный скилл ставить не нужно — инструкция вшита в коннектор и приходит клиенту при подключении. В любом чате:

- «Заведи базу под AI-инструменты для видеомонтажа»
- «Исследуй тему агентов для продаж и сохрани в базу»
- «Что у нас в каталоге по видео?»

**Как идёт исследование:** подтемы → сверка с каталогом (что уже есть) → веб-поиск силами самого Claude Code → отчёт с источниками → по твоему согласию запись в базу.

## Часть 2. Сайт — для тех, кто не в Claude Code

### Доступ

Вход через Google, только по списку допущенных. Сейчас в списке:
`ceo@aivocado.ai`, `d.soloviov@aivocado.ai`, `s.vedenieva@aivocado.ai`, `sergey.glova@gmail.com`, `v.pushkar@aivocado.ai`.

Добавить человека: вписать почту в `ALLOWED_EMAILS` (локально и в Vercel), затем передеплоить. Входить нужно **именно тем адресом**, который в списке.

### Ключ для исследования

Живой веб-поиск на сайте включается переменной `OPENROUTER_API_KEY` в Vercel (Production). Отдельный ключ поисковика не нужен — поиск идёт плагином OpenRouter.

Опционально `OPENROUTER_MODEL` — по умолчанию `anthropic/claude-sonnet-4.5`.

Перенести ключ из локального файла в Vercel (PowerShell):

```powershell
cd C:\Users\nehoc\ai-researcher
$k = ((Get-Content .env.local | Select-String '^OPENROUTER_API_KEY=').Line -replace '^OPENROUTER_API_KEY=','').Trim()
$k | npx vercel env add OPENROUTER_API_KEY production
```

После добавления любой переменной — **редеплой**:

```bash
npx vercel --prod --force --yes
```

### Как понять, что работает

У каждого блока отчёта метка: **🌐 веб** — найдено в интернете, **📁 каталог** — собрано из базы. Если веб не отработал, наверху пишется причина: кончились кредиты, отклонён ключ или сработал лимит частоты.

## Частые проблемы

| Симптом | Причина и что делать |
|---|---|
| В отчёте всюду «📁 каталог», сверху про кредиты | Пустой баланс OpenRouter → пополнить на openrouter.ai/settings/credits |
| «Ключ OpenRouter отклонён» | Неверный или просроченный `OPENROUTER_API_KEY` в Vercel |
| Каталог пустой, «0 из 412» | Неверный `SUPABASE_SERVICE_KEY`. Нужен ключ вида `sb_secret_…` (Settings → API Keys → Secret keys), а **не** legacy-JWT `eyJ…` |
| После логина не пускает | Почты нет в `ALLOWED_EMAILS` либо вход другим Google-аккаунтом |
| Изменения не видны после деплоя | Жёсткое обновление `Ctrl+Shift+R` — страница кэшируется браузером |
| В Claude Code нет инструментов | Коннектор не подключён: проверить `~/.claude.json` и перезапустить Claude Code |
