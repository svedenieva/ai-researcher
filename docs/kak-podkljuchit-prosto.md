# Как подключить Claude Design к сайту ИИ-Исследователь

> Простая инструкция для человека, который раньше этого не делал.
> Просто повторяй шаги сверху вниз. Ничего ломать нельзя — если что-то не получилось, смотри раздел «Если не вышло» в конце.

---

## Что мы вообще делаем

Мы соединяем две вещи, чтобы они «разговаривали» друг с другом:

- **Claude Design** — сайт, где ты рисуешь и правишь дизайн мышкой.
- **Сайт ИИ-Исследователь** — сам продукт, его код.

После настройки картинки из дизайна и код сайта будут связаны. Это соединение называется **«мост»**.

Всё делается через одну чёрную программу с текстом — она называется **терминал**. Не пугайся: ты просто вставляешь готовые команды и жмёшь Enter.

---

## Что нужно до начала

1. На компьютере должна быть установлена программа **Claude Code**.
   (Если её нет — попроси того, кто дал тебе эту инструкцию, установить её один раз.)
2. Твой аккаунт должен иметь доступ к **Claude Design**.
   Это важнее всего. Без доступа ничего не заработает, даже если всё сделать правильно.
   Как проверить — на шаге 4 будет видно.

---

## Шаг 1. Открыть терминал

- **Windows:** нажми `Пуск`, набери слово `powershell`, открой его.
- **Mac:** нажми `Cmd + пробел`, набери `terminal`, открой его.

Откроется окно с текстом. Сюда мы будем вставлять команды.

> 💡 Вставить команду: скопируй её отсюда, кликни в окно терминала, нажми `Ctrl + V` (на Mac — `Cmd + V`), потом `Enter`.

---

## Шаг 2. Добавить «мост» (делается один раз)

Скопируй эту строку целиком, вставь в терминал и нажми Enter:

```
claude mcp add --scope user --transport http claude-design https://api.anthropic.com/v1/design/mcp
```

Если появилась строчка без слова «error» — всё хорошо, идём дальше.

---

## Шаг 3. Запустить программу

Набери в терминале одно слово и нажми Enter:

```
claude
```

Программа запустится. Дальше команды пишем **внутри неё**.

---

## Шаг 4. Войти в дизайн

Внутри программы набери и нажми Enter:

```
/design-login
```

Откроется браузер — войди в свой аккаунт, как обычно входишь на сайт.

**Что должно появиться после входа:**

```
Design-system access authorized.
```

✅ Появилось — отлично, доступ есть, продолжаем.
❌ Появилось слово **403** или «rejected» — значит у аккаунта нет доступа к Claude Design. Сам это не починишь: напиши тому, кто дал инструкцию, «у меня 403 на design-login» — доступ включают со стороны аккаунта.

---

## Шаг 5. Проверить, что мост работает

Внутри программы набери:

```
/mcp
```

Найди в списке строку **claude-design**. Рядом должно быть зелёным написано что-то вроде **Reconnected** или **connected**.

🎉 Если да — **всё готово, мост подключён.** Можно пользоваться.

---

## Как теперь пользоваться

- Заходишь на сайт **claude.ai/design**, открываешь свой проект и правишь дизайн как хочешь — мышкой, текстом, комментариями. Код трогать не надо.
- Когда закончил и хочешь, чтобы правки ушли в сайт — просто скажи об этом в чате словами: **«отправь в git»**. Дальше всё произойдёт само.

---

## Если не вышло

| Что видишь | Что делать |
|---|---|
| После `/design-login` — **403** или «rejected» | Доступа к Claude Design нет. Напиши: «у меня 403 на design-login» тому, кто дал инструкцию. |
| `/design-login` вообще не запускается | Ты не внутри программы. Сначала набери `claude` (шаг 3), потом `/design-login`. |
| В `/mcp` строка **claude-design** красная или её нет | Повтори шаг 4 (`/design-login`) ещё раз. |
| Не знаешь, куда вставлять команду | Все команды со `/` (слэшем) — пишутся **внутри** программы (после шага 3). Команда `claude mcp add …` — в обычном терминале (шаг 2). |
| Совсем застрял | Сделай скриншот того, что на экране, и отправь тому, кто дал инструкцию. |

---

## Коротко, одним взглядом

1. Открыть терминал
2. Вставить команду `claude mcp add …` → Enter
3. Написать `claude` → Enter
4. Написать `/design-login` → войти → увидеть «authorized»
5. Написать `/mcp` → claude-design зелёный → **готово**
