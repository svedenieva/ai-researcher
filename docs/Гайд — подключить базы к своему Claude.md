# Базы знаний в своём Claude — подключение за 2 минуты

**Кому:** команде AiVocado Soft
**Зачем:** в любом чате сказать «заведи базу под такую-то тему» или «исследуй тему и сохрани» — Claude разложит на подтемы, сверится с каталогом, найдёт информацию и запишет результат в витрину.

Ничего устанавливать не нужно — только одна ссылка и личный токен.

---

## 1. Подключить

### Шаг 1. Открыть конфиг Claude

Файл `~/.claude.json`:
- Windows — `C:\Users\ИМЯ\.claude.json`
- Mac — `/Users/ИМЯ/.claude.json`

Открывается любым текстовым редактором.

### Шаг 2. Добавить сервер

Внутри раздела `mcpServers` добавить блок. Если раздела нет — создать его на верхнем уровне:

```json
{
  "mcpServers": {
    "ai-researcher": {
      "type": "http",
      "url": "https://ai-reesearcher.vercel.app/api/mcp",
      "headers": {
        "Authorization": "Bearer ВАШ_ТОКЕН"
      }
    }
  }
}
```

Вместо `ВАШ_ТОКЕН` подставьте токен, который вам прислали лично. Он выглядит как `mcp_XXXXXXXXXXXX`.

### Шаг 3. Перезапустить Claude

Полностью закрыть и открыть заново — иначе новый сервер не подхватится.

### Если клиент не принял блок выше

Некоторые версии (чаще Claude Desktop) не понимают `"type": "http"`. Тогда тот же сервер подключается через мостик — ставить ничего не надо, `npx` скачает сам:

```json
{
  "mcpServers": {
    "ai-researcher": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://ai-reesearcher.vercel.app/api/mcp",
        "--header", "Authorization: Bearer ВАШ_ТОКЕН"
      ]
    }
  }
}
```

Нужен установленный Node.js. Всё остальное — так же: сервер и ключи остаются на нашей стороне.

> ⚠️ **Токен личный.** По нему определяется, чьи базы вы видите. Не пересылайте его в общие чаты и не публикуйте.

## 2. Как пользоваться

Пишите обычными словами — правила работы Claude получает автоматически при подключении, скилл ставить не нужно.

- «Заведи базу под AI-инструменты для видеомонтажа»
- «Исследуй тему агентов для продаж и сохрани в базу»
- «Что у нас уже есть в каталоге по маркетингу?»
- «Добавь эти компании в мою базу» (можно вставить список)

**Как идёт исследование:** тема разбивается на подтемы → Claude сверяется с каталогом, что уже известно → ищет в интернете то, чего нет → показывает отчёт с источниками → и только после вашего согласия записывает в базу. Компании помечаются «уже в базе» или «новое».

**Где смотреть результат:** всё записанное появляется на витрине https://ai-reesearcher.vercel.app — вход через Google тем же адресом, что привязан к вашему токену.

## 3. Кто что видит

| Что | Кому видно |
|---|---|
| **Каталог продуктов** (Рынок AI, AI-сфера, IT-сфера, Workforce) | всем — это общая база компаний |
| **Базы, которые вы завели** | только вам |
| **Общие базы** (заведены без владельца) | всем |
| **Чужие личные базы** | никому, кроме владельца — даже по прямой ссылке |

Базы можно вкладывать друг в друга: например, свой раздел внутри AI-сферы. Раздел показывает и то, что лежит внутри него.

## 4. Если не работает

### Быстрая проверка

Откройте в браузере ссылку со своим токеном:

```
https://ai-reesearcher.vercel.app/api/mcp?token=ВАШ_ТОКЕН
```

Должно ответить `"authorized": true` и вашу почту. Если `false` — токен неверный или скопирован не целиком.

### Частые случаи

| Симптом | Что делать |
|---|---|
| В чате нет инструментов баз | Claude не перезапущен, либо блок вставлен не в `mcpServers` |
| «Нужен действующий токен доступа» | Токен не подставлен или устарел — запросите новый |
| «Нет доступа к этой базе» | База личная и принадлежит другому человеку |
| Записал, а на сайте не видно | Обновите страницу через `Ctrl+Shift+R` и проверьте, что вошли тем же адресом |
| Ошибка про JSON в конфиге | Потеряна запятая или скобка — проверьте файл целиком |
