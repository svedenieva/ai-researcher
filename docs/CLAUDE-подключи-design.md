# Задача для Claude: подключить мост Claude Design ↔ ИИ-Исследователь

> **Это инструкция для тебя, Claude Code.** Человек кинул тебе этот файл и сказал «подключи».
> Выполни процедуру ниже сам, от начала до конца. Останавливайся и проси человека
> действовать ТОЛЬКО в двух местах, явно помеченных 🙋 **НУЖЕН ЧЕЛОВЕК**.
> Не переходи к следующему шагу, пока не прошла проверка текущего.

## Цель
Поднять MCP-мост `claude-design` в этом репозитории (`ai-researcher`, github.com/svedenieva/ai-researcher),
проверить сквозной доступ к Claude Design и синхронизировать компоненты сайта в дизайн-проект.

## Контекст, который тебе важно знать заранее
- Есть две сущности: встроенный инструмент **DesignSync** (чтение/синхронизация дизайн-проектов) и MCP-сервер **claude-design**. Оба авторизуются одним входом claude.ai через `/design-login`.
- **Вход `/design-login` и доступ к Claude Design ты сам сделать не можешь** — это делает человек в интерактивном терминале, а доступ к preview включается на уровне аккаунта. Это единственные ручные точки.
- Частый провал — **403 / FIRST_PARTY_AUTH_REJECTED**: вход прошёл, но у аккаунта нет доступа к Claude Design. Конфигом не лечится.

---

## Шаг 1 — Добавить MCP-коннектор (делаешь сам)
Выполни:
```bash
claude mcp add --scope user --transport http claude-design https://api.anthropic.com/v1/design/mcp
```
Если коннектор уже есть — команда сообщит об этом, это нормально, продолжай.
**Проверка:** команда завершилась без ошибки.

## Шаг 2 — Проверить, есть ли уже доступ (делаешь сам)
Загрузи инструмент и попробуй прочитать проекты:
```
ToolSearch select:DesignSync
```
затем вызови `DesignSync` с методом `list_projects`.

Разветвление по результату:
- ✅ **Вернулся список проектов** — доступ уже есть, вход не нужен. Переходи сразу к Шагу 4.
- ❌ **Ошибка авторизации / 403 / "needs authentication"** — доступа пока нет. Переходи к Шагу 3.

## Шаг 3 — 🙋 НУЖЕН ЧЕЛОВЕК: вход
Остановись и попроси человека сделать ровно это (своими словами, коротко):

> «Открой интерактивный терминал в этой папке, набери `claude`, потом `/design-login` и войди в аккаунт. Скажи мне, когда увидишь надпись **Design-system access authorized**.»

Дождись ответа человека. После этого **повтори Шаг 2** (`DesignSync list_projects`).

- ✅ Список вернулся → идём дальше (Шаг 4).
- ❌ Снова **403 / rejected** → это не чинится входом. Сообщи человеку дословно:
  > «Вход прошёл, но аккаунт не имеет доступа к Claude Design (preview) — ошибка 403. Это включается на стороне аккаунта, я не могу сделать это сам. Напиши тому, кто выдаёт доступы: "нужен доступ к Claude Design preview для этого аккаунта". Как включат — снова скажи мне "подключи", я продолжу.»
  И **останови процедуру** — дальше без доступа смысла нет.

## Шаг 4 — Навести мост: код → дизайн (делаешь сам)
Убедись, что работаешь в корне репозитория `ai-researcher`. Запусти скилл синхронизации:
```
Skill: design-sync
```
(или слэш-командой `/design-sync`, если так удобнее в текущей сессии.)

- При первом запуске `.design-sync/` в репозитории ещё нет — скилл проведёт первичную настройку: спросит/определит целевой дизайн-проект (существующий из `list_projects` или новый) и состав компонентов.
- **Покажи человеку план ДО записи** (какие компоненты и в какой проект зальются) и дождись подтверждения — запись в дизайн-проект и в репозиторий делай только после «ок».
- Синхронизируй инкрементально; на повторных запусках обновляй связанные карточки, не плоди дубли.

## Шаг 5 — Закоммитить «паспорт» моста (делаешь сам, с подтверждения)
Появившуюся папку `.design-sync/` (конфиг: id проекта, состав компонентов) предложи закоммитить, чтобы у следующего человека мост поднимался сразу:
```bash
git add .design-sync
git commit -m "chore(design): подключить мост claude-design (design-sync config)"
```
Коммить только после «ок» человека. Не пуш и не PR без отдельной просьбы.

## Финальный отчёт человеку
Когда всё прошло — отчитайся коротко и по факту:
- коннектор `claude-design` добавлен ✅
- доступ к Claude Design проверен (list_projects отвечает) ✅
- `/design-sync` выполнен, целевой проект: `<название и id>` ✅
- `.design-sync/` закоммичен ✅ (или: ждёт пуша)

И одной фразой — что человек делает дальше: правит дизайн на claude.ai/design, а по готовности говорит «отправь в git».

## Стоп-условия (не притворяйся, что получилось)
- Не пиши «подключено», если `DesignSync list_projects` не вернул список — это единственное доказательство живого доступа.
- 403 после входа — это отсутствие доступа у аккаунта, а не твоя ошибка; честно скажи об этом и останови процедуру.
- Ничего не пушь и не открывай PR без явной просьбы человека.
