Базы знаний в своём Claude — подключение за 2 минуты

После подключения в любом чате можно сказать «заведи базу под такую-то тему» или «исследуй тему и сохрани» — Claude сам разложит на подтемы, сверится с каталогом, найдёт информацию и запишет результат в витрину.

Ставить ничего не нужно — только адрес и личный токен
01 Обычный способ в приложении Claude, без файлов и кода

Подходит и для сайта claude.ai, и для настольного приложения. Правки файлов не нужны.

Шаг 1. Открыть настройки коннекторов
В Claude: Настройки → Коннекторы (в англоязычном интерфейсе — Settings → Connectors). Внизу списка — Добавить свой коннектор / «Add custom connector».
Шаг 2. Заполнить два поля
Название — AI-Researcher.
Адрес сервера — вставить строку целиком, подставив свой токен:
https://ai-reesearcher.vercel.app/api/mcp?token=ВАШ_ТОКЕН
Шаг 3. Сохранить и начать новый чат
Коннектор появится в списке доступных. В уже открытом чате он не подхватится — нужен новый.

Токен личный и лежит прямо в адресе. По нему определяется, чьи базы вы видите. Не показывайте этот адрес на демонстрации экрана и не пересылайте в общие чаты — попросите свой токен лично.

Названия пунктов меню у разных версий Claude чуть отличаются, но смысл один: добавить свой (custom) коннектор по адресу удалённого MCP-сервера.

02 Если вы в Claude Code блок в ~/.claude.json
Шаг 1. Открыть конфиг
Файл ~/.claude.json: на Windows — C:\Users\ИМЯ\.claude.json, на Mac — /Users/ИМЯ/.claude.json. Открывается любым текстовым редактором.
Шаг 2. Добавить сервер
Внутрь раздела mcpServers. Если раздела нет — создать его на верхнем уровне.
{
  "mcpServers": {
    "ai-researcher": {
      "type": "http",
      "url": "https://ai-reesearcher.vercel.app/api/mcp",
      "headers": {
        "Authorization": "Bearer ВАШ_ТОКЕН"
      }
    }
  }
}
Шаг 3. Перезапустить Claude
Полностью закрыть и открыть заново — иначе новый сервер не подхватится.
Если клиент не понял "type": "http"
Некоторые версии подключаются через мостик. Ставить ничего не надо — npx скачает сам; нужен установленный Node.js.
{
  "mcpServers": {
    "ai-researcher": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://ai-reesearcher.vercel.app/api/mcp",
        "--header", "Authorization: Bearer ВАШ_ТОКЕН"
      ]
    }
  }
}
03 Как пользоваться обычными словами, без команд

Правила работы Claude получает автоматически при подключении — скилл ставить не нужно.

  • «Заведи базу под AI-инструменты для видеомонтажа»
  • «Исследуй тему агентов для продаж и сохрани в базу»
  • «Что у нас уже есть в каталоге по маркетингу?»
  • «Добавь эти компании в мою базу» — список можно просто вставить
Как идёт исследование
Тема разбивается на подтемы → Claude сверяется с каталогом, что уже известно → ищет в интернете то, чего нет → показывает отчёт с источниками → и только после вашего согласия записывает в базу. Компании помечаются «уже в базе» или «новое».
Что умеет коннекторЗачем
list_basesпоказать дерево баз
create_baseзавести базу под тему, можно сразу внутрь раздела
add_rowsдописать строки
query_recordsпрочитать записи базы
update_recordпоправить отдельные поля
catalog_searchнайти компании в общем каталоге
research_decomposeразложить тему на подтемы

Результат появляется на витрине ai-reesearcher.vercel.app — вход через Google тем же адресом, что привязан к вашему токену.

05 Если не работает проверка за 10 секунд
Быстрая проверка
Откройте в браузере тот же адрес, что вставляли в коннектор. Ответ должен содержать "authorized": true и вашу почту. Если false — токен неверный или скопирован не целиком.
https://ai-reesearcher.vercel.app/api/mcp?token=ВАШ_ТОКЕН
СимптомЧто делать
В чате нет инструментов базчат открыт до подключения — начните новый; в Claude Code — перезапустите приложение
«Нужен действующий токен доступа»токен не подставлен или устарел — запросите новый
«Нет доступа к этой базе»база личная и принадлежит другому человеку
Записал, а на сайте не виднообновите страницу через Ctrl+Shift+R и проверьте, что вошли тем же адресом
Ошибка про JSON в конфигепотеряна запятая или скобка — проверьте файл целиком
