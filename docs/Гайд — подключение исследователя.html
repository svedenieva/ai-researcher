AI-Researcher: как подключить и на чём он работает

Как завести базу под новую тему и провести исследование — из чата Claude Code (на своей подписке) или на сайте (для команды). Ниже: подключение, проверка, частые проблемы.

Claude Code — свой чат
Думает сам Claude Code, он же ищет в вебе. Нужен только подключённый MCP-коннектор.
на подписке · без ключей
Сайт ai-reesearcher
Модель вызывается с сервера, поэтому нужен ключ на проекте. Для тех, кто не работает в Claude Code.
OpenRouter · по токенам
00 Почему два режима подписку нельзя подставить в сайт

Подписка привязана к человеку и не делится между сотрудниками, а для многопользовательского сервиса Anthropic прямо направляет на API-ключ. Поэтому личная работа в Claude Code идёт на подписке, а сайт для команды — на OpenRouter.

01 Claude Code — подключение коннектор, проверка, первые команды
Шаг 1. Коннектор в конфиге
Уже прописан глобально в ~/.claude.json — работает в любом чате:
{
  "mcpServers": {
    "ai-researcher": {
      "command": "node",
      "args": ["C:/Users/nehoc/ai-researcher/mcp/server.mjs"]
    }
  }
}
Секрет вписывать не нужно: сервер сам берёт SUPABASE_URL и SUPABASE_SERVICE_KEY из .env.local витрины.

После правки конфига перезапусти Claude Code — иначе коннектор не подхватится.

Шаг 2. Проверить
cd C:/Users/nehoc/ai-researcher/mcp
node test-client.mjs
Должно вывести 7 инструментов: list_bases, create_base, add_rows, query_records, update_record, catalog_search, research_decompose. Тестовую базу, если создалась, удали.
Шаг 3. Пользоваться
Отдельный скилл ставить не надо — инструкция вшита в коннектор и приходит при подключении. В любом чате:
  • «Заведи базу под AI-инструменты для видеомонтажа»
  • «Исследуй тему агентов для продаж и сохрани в базу»
  • «Что у нас в каталоге по видео?»
Как идёт исследование: подтемы → сверка с каталогом (что уже есть) → веб-поиск силами самого Claude Code → отчёт с источниками → по твоему согласию запись в базу.
02 Сайт — для команды доступ, ключ, как понять что работает
Доступ
Вход через Google, только по списку допущенных. Добавить человека — вписать почту в ALLOWED_EMAILS (локально и в Vercel) и передеплоить. Входить нужно именно тем адресом, который в списке.
Ключ для исследования
Живой веб-поиск включается переменной OPENROUTER_API_KEY в Vercel (Production). Отдельный ключ поисковика не нужен. Модель по умолчанию — anthropic/claude-sonnet-4.5, меняется через OPENROUTER_MODEL.
cd C:\Users\nehoc\ai-researcher
$k = ((Get-Content .env.local | Select-String '^OPENROUTER_API_KEY=').Line -replace '^OPENROUTER_API_KEY=','').Trim()
$k | npx vercel env add OPENROUTER_API_KEY production
После добавления любой переменной — редеплой:
npx vercel --prod --force --yes
Как понять, что работает
У каждого блока отчёта метка: 🌐 веб — найдено в интернете, 📁 каталог — собрано из базы. Если веб не отработал, наверху пишется причина: кончились кредиты, отклонён ключ или сработал лимит частоты.
03 Частые проблемы симптом → причина → что делать
СимптомПричина и что делать
Всюду «📁 каталог», сверху про кредитыПустой баланс OpenRouter → пополнить на openrouter.ai/settings/credits
«Ключ OpenRouter отклонён»Неверный или просроченный OPENROUTER_API_KEY в Vercel
Каталог пустой, «0 из 412»Неверный SUPABASE_SERVICE_KEY. Нужен ключ вида sb_secret_… (Settings → API Keys → Secret keys), а не legacy-JWT eyJ…
После логина не пускаетПочты нет в ALLOWED_EMAILS либо вход другим Google-аккаунтом
Изменения не видны после деплояЖёсткое обновление Ctrl+Shift+R — страница кэшируется браузером
В Claude Code нет инструментовКоннектор не подключён: проверить ~/.claude.json и перезапустить Claude Code
