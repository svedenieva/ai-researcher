# BaseTree

Дерево баз знаний с полным набором операций над узлом: переименовать,
переместить, удалить, создать вложенную. Каждая ветка несёт свой цвет-тон
(`--tone-sage` / `teal` / `blue` / `amber`). В режиме `embedded` рисуется как
панель внутри страницы, иначе — как оверлей.
