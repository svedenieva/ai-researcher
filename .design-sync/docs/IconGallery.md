# IconGallery

Весь набор иконок продукта одной карточкой. Иконки — Feather-подобные, обводка
`currentColor`, размер задаётся пропом `size`, поэтому они наследуют цвет и
кегль места, куда поставлены.

Каждая иконка доступна и отдельно: `IconFolder`, `IconTrash`, `IconSearch` и
остальные 24 — обычные экспорты, галерея нужна только для просмотра.
